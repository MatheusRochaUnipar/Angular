# Angular — Projetos Acadêmicos

Repositório com projetos desenvolvidos durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)** na UNIPAR, utilizando **Angular**.

## 📁 Projetos

### [`meu-primeiro-projeto`](./meu-primeiro-projeto)
Primeiro projeto Angular desenvolvido para estudo dos conceitos básicos do framework: componentes, data binding e estrutura de pastas.

### [`calculadora-css`](./calculadora-css)
Projeto focado em estilização com CSS, implementando uma calculadora com interface personalizada.

### [`exemplo-listas`](./exemplo-listas)
Exemplos práticos de manipulação e renderização de listas em Angular (diretivas estruturais como `*ngFor`).

### [`exercicios-1bimestre`](./exercicios-1bimestre)
Exercícios desenvolvidos durante o primeiro bimestre da disciplina.

### [`trabalho-1bimestre`](./trabalho-1bimestre)
Trabalho avaliativo do primeiro bimestre.

## 🛠️ Tecnologias

- [Angular](https://angular.dev/)
- TypeScript
- HTML5 / CSS3

## ▶️ Como rodar um projeto

Cada pasta é um projeto Angular independente. Para rodar:

```bash
cd nome-do-projeto
npm install
ng serve
```

Depois acesse `http://localhost:4200` no navegador.
